Configurar la IA

Esta versión funciona con tu propia clave de API. La clave se guarda solo en este navegador y se envía únicamente a la empresa que elijas. El uso se cobra en tu cuenta de esa empresa.

¿No tienes una? Sácala aquí (se abre en otra pestaña).

Cómo sacar una clave, paso a paso
Anthropic (Claude)
Entra en console.anthropic.com con tu correo → Settings → Billing: carga saldo (desde unos pocos dólares) → API keys → Create key → copia la clave (empieza con sk-ant-).
OpenAI (ChatGPT)
Entra en platform.openai.com → Settings → Billing: carga saldo → API keys → Create new secret key → copia la clave (empieza con sk-). La suscripción a ChatGPT Plus no sirve para la API.
Google (Gemini)
Entra en aistudio.google.com con una cuenta de Google → Get API key → Create API key → copia la clave. Puedes empezar sin pagar, con el plan gratuito.
Seguridad y costos
  • La clave es como una contraseña: no la compartas ni la uses en computadoras públicas. Quien use este navegador puede usarla.
  • Para cuidar el gasto, en la página de tu cuenta puedes fijar un límite mensual.
  • Adaptar un cuento de unas 2.000 palabras cuesta, aproximadamente, entre menos de un centavo y unos 50 centavos de dólar según el modelo.
  • «Copiar mis datos» no copia la clave: en otro dispositivo hay que volver a cargarla.
