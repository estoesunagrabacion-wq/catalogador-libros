    Bienvenida a Lectura Fácil

    Una aplicación para adaptar textos a Lectura Fácil, con pictogramas, glosario y PDF para imprimir en A5 o en cuadernillo.

    1. Necesitas una cuenta de Claude (gratuita, en claude.ai) con la sesión iniciada.
    2. Ábrela siempre desde el enlace. No descargues el archivo: descargado no funciona.
    3. La primera vez que pulses «Adaptar texto», elige «Permitir».
    4. El botón de Ayuda (?), arriba, explica todo paso a paso.

    Cómo usar Lectura Fácil

    Esta aplicación adapta textos de clase a Lectura Fácil para cada estudiante, con pictogramas, glosario y versión A5 para imprimir. La adaptación la hace Claude, una inteligencia artificial.

    1. Qué necesitas
    • Una cuenta de Claude, gratuita o de pago. Se crea en claude.ai con un correo.
    • Iniciar sesión en ese navegador o en la app de Claude, en cada dispositivo donde la uses.
    • El enlace de esta aplicación (te lo comparte quien la creó).
    • La primera vez que pulses «Adaptar texto», Claude te pregunta si permites que la aplicación lo use. Elige Permitir.

    Cada docente usa su propia cuenta. Las adaptaciones cuentan para el uso de tu cuenta; la cuenta gratuita tiene un límite diario.

    2. Primeros pasos
    1. En Estudiante, elige el curso y cómo lee. Con «+ Nuevo» puedes crear un perfil para cada estudiante.
    2. Elige la materia y el tipo de texto (cuento, poema, texto del libro, problemas o consignas).
    3. Pega el texto y elige cuánto simplificar.
    4. Pulsa Adaptar texto y espera entre 20 segundos y 2 minutos.
    5. Lee el recuadro amarillo Para revisar: dice qué se cambió.
    6. Para corregir algo, pulsa ✏️ Editar, toca el texto y cámbialo. Tocando un pictograma puedes elegir otro. Al terminar, pulsa ✓ Listo.
    7. Si falta una palabra en el glosario, escríbela y pulsa + Agregar al glosario.
    8. Con Guía del original activada, cada parte muestra de qué párrafo del texto original sale y sus primeras palabras («Original ¶3: …»), para seguir la lectura junto con la clase.
    9. Usa Vista alumna para que lo lea en pantalla, 📄 Imprimir para el PDF en A5 o en cuadernillo, o Descargar Word para editarlo.
    3. Usarla en el celular o en otra computadora
    1. Abre el mismo enlace en el otro dispositivo.
    2. Inicia sesión en Claude con tu cuenta.
    3. Para tener un ícono como el de una app:
      Android (Chrome): menú ⋮ → Añadir a pantalla de inicio.
      iPhone (Safari): botón Compartir → Agregar a inicio.
    4. Tus estudiantes y textos guardados no se pasan solos de un dispositivo a otro. Usa la sección 5 para llevarlos.

    Enlace: https://claude.ai/artifact/TuAXtS8wJKRVgVUtL4ePrE

    4. Si algo no funciona
    El botón «Adaptar texto» está gris
    No hay sesión de Claude en este navegador, o la página se abrió fuera de Claude. Inicia sesión en claude.ai y vuelve a abrir el enlace.
    Dice «No se dio permiso» o «no tiene permiso»
    Pulsa el botón Dar permiso y activa Claude. Si no aparece, busca el menú Permisos de la página en la barra de Claude, arriba.
    Dice «Claude no está disponible en esta ventana»
    No uses ventana privada o de incógnito. Desactiva el bloqueo de cookies o los bloqueadores de anuncios para claude.ai, o prueba en Chrome o Edge.
    Aparece una línea «Diagnóstico…»
    Si no logras que funcione, copia esa línea y envíasela a quien te compartió la aplicación.
    Dice que se hicieron muchas adaptaciones
    Llegaste al límite de uso de tu cuenta por un rato. Espera y vuelve a intentarlo.
    «La respuesta llegó incompleta»
    El texto es muy largo. Adáptalo en dos o tres partes.
    No se descarga el PDF o el Word
    Aparece una ventana para confirmar la descarga: acéptala. En el celular, el archivo queda en «Descargas».
    No encuentro mis estudiantes o textos
    Se guardan en cada dispositivo y navegador. Si borraste los datos del navegador o cambiaste de dispositivo, impórtalos (sección 5).
    5. Llevar mis datos a otro dispositivo

    En este dispositivo, pulsa Copiar mis datos y envíate el texto (por WhatsApp o correo). En el otro dispositivo, pégalo abajo y pulsa Importar.

    6. Compartir con otros docentes
    1. Quien creó la aplicación pulsa Compartir, en la barra de Claude arriba de la página.
    2. Puede invitar por correo o crear un enlace y enviarlo.
    3. Cada docente necesita su propia cuenta de Claude (sección 1). Lo que guarda cada uno no lo ven los demás.
